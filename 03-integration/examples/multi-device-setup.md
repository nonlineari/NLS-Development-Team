# Multi-Device Setup

## Overview

This guide explains how to set up and coordinate multiple NLS tracker devices for collaborative performances.

## Device Coordination

### Device Discovery
- Use mDNS for automatic device discovery
- Assign unique device IDs
- Configure device roles (master/slave)

### Synchronization
- Use NTP for time synchronization
- Coordinate data collection timing
- Synchronize OSC messages
