# Basic Setup Example

## Overview

This guide provides a step-by-step example for basic setup and integration of the NLS tracker device.

## Prerequisites

- NLS tracker device assembled and powered
- Computer with development environment
- WiFi network access

## Steps

### 1. Connect Device
- Power on device
- Connect to device WiFi (AP mode) or configure WiFi credentials

### 2. Configure Device
- Access web interface at `http://192.168.4.1`
- Configure WiFi, sensors, and communication settings

### 3. Test Sensors
- Verify sensor data is being collected
- Check data transmission via MQTT or WebSocket

### 4. Integrate with NLS
- Configure OSC connection to TidalCycles
- Test sensor data mapping to audio parameters
