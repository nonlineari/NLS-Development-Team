# API Overview

## Overview

This document provides an overview of the NLS tracker device APIs.

## API Types

### 1. REST API
- HTTP/HTTPS endpoints
- JSON request/response
- Web-based access

### 2. WebSocket API
- Real-time bidirectional communication
- Binary and text messages
- Low latency

### 3. MQTT API
- Publish-subscribe messaging
- Topic-based communication
- QoS levels

### 4. CLI API
- Command-line interface
- Serial/USB access
- Script automation
