# CLI Reference

## Overview

Command-line interface for device control and configuration.

## Commands

### Status
```bash
status
# Shows device status
```

### Configuration
```bash
config get
config set <key> <value>
```

### Sensors
```bash
sensors list
sensors enable <sensor>
sensors disable <sensor>
```

### Network
```bash
wifi scan
wifi connect <ssid> <password>
```
