# Hardware Setup

## Overview

This guide walks you through the hardware setup process for the NLS tracker device.

## Prerequisites

- Assembled NLS tracker device (see [Assembly Guide](../../01-hardware/assembly/assembly-guide.md))
- USB-C cable
- Computer with USB port
- Power supply (optional, for testing)

## Initial Setup

### 1. Power On Device
- Connect USB-C cable to device
- Connect to computer or power supply
- Verify power LED is on

### 2. Connect to Device
- **WiFi AP Mode**: Connect to "NLS-Tracker-XXXX" network
- **Default IP**: 192.168.4.1
- **Web Interface**: http://192.168.4.1

### 3. Initial Configuration
- Set device name and ID
- Configure WiFi credentials
- Set timezone and location
